# Image Editor

A lightweight browser-based image editing tool built using HTML, CSS, and Vanilla JavaScript. It allows users to upload images, apply real-time filters and presets, make adjustments, and download the edited image directly from the browser.

The project uses the HTML5 Canvas API for dynamic image manipulation without relying on external frameworks.

## Features

- Upload and preview images instantly
- Real-time filter adjustments using sliders
- Multiple image filters:
  - Brightness
  - Contrast
  - Saturation
  - Hue Rotate
  - Blur
  - Grayscale
  - Invert
  - Opacity
- Preset filter styles:
  - Vintage
  - Cyber Punk
  - Retro Pop
  - Black & White
  - And more
- Reset functionality to restore the original image
- Download edited images directly from the browser
- Responsive user interface for different screen sizes

## Tech Stack

- HTML5
- CSS3
- Flexbox
- Responsive Design
- CSS Variables
- Vanilla JavaScript
- HTML5 Canvas API
